API 使用信息

1. 临时邮箱API (Mail.tm)

2. 发送验证码API

基本URL: http://xiaoxun.my/api/v1/send.php

专为移动端优化的邮件发送API，支持多种验证码邮件模板

快速发送

支持GET/POST请求，简单参数即可发送验证码邮件

接口端点
  • 发送邮件: http://xiaoxun.my/api/v1/send.php
  • 生成验证码: http://xiaoxun.my/api/v1/send.php?action=generate-code
  • 模板列表: http://xiaoxun.my/api/v1/send.php?action=templates
参数说明
  • template: 邮件模板类型 (login, register, privacy, important, reset)
  • source: 来源名称，显示在邮件主题和发件人中
  • code: 3-12位英文字母数字验证码
  • to_email: 收件人邮箱地址
  • proxy_email: 代理发件邮箱 (可选)
JavaScript调用示例
fetch('http://xiaoxun.my/api/v1/send.php', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/x-www-form-urlencoded',
  },
  body: new URLSearchParams({
    template: 'login',
    source: '小胡临时邮箱',
    code: 'ABC123',
    to_email: 'user@example.com'
  })
})
.then(res => res.json())
.then(data => console.log(data));
